# Creador de Clases (Java Code Generator)

## Project Overview

This directory contains a custom Java command-line application designed to interactively generate Java boilerplate code. It acts as a cheat/utility for the "Programacion 2" (Object-Oriented Programming) university course at U.N.L.P.

The tool allows users to dynamically build representations of Java classes by specifying:
- Class names
- Whether the class is abstract
- Inheritance (base classes)
- Member variables (types and names)
- Abstract methods

Based on these inputs, the application automatically generates the corresponding Java source code, including fields, constructors (empty, full, and calling `super()`), getters, setters, overridden methods, and `toString()` implementations. The generated code is printed to the console.

## Architecture and Key Files

The project follows an object-oriented design to represent the structure of a Java class before generating the string output:

*   **`GeneradorDeClases.java`**: The main entry point of the application. It runs the interactive console menu (Create, Show, Modify, Show All, Exit).
*   **`Clase.java`**: Represents a Java class. It holds the class name, inheritance data, variables, and methods. It contains the core logic (`generarCodigo()`) to build the final Java string representation based on its properties.
*   **`CrearClase.java`**: Handles the interactive prompt logic for defining a new class, variables, and methods from the user input.
*   **`ModificarClase.java`**: Logic for modifying an existing class model.
*   **`Variable.java`** / **`MetodoAbstracto.java`**: Models for representing class fields and methods.
*   **`TipoUtil.java`**: Utility for determining and prompting for Java data types.
*   **`Capitalize.java`** / **`Sangria.java`**: Formatting utilities to handle casing (CamelCase) and indentation of the generated code.

## Building and Running

Since this is a standard Java console application without a package manager (like Maven or Gradle), you can compile and run it directly using the JDK tools.

1.  **Compile the source files:**
    ```bash
    javac *.java
    ```

2.  **Run the application:**
    ```bash
    java GeneradorDeClases
    ```

## Development Conventions

- The project relies on `Scanner(System.in)` for user input.
- Classes generated by this utility are outputted to `System.out` rather than saved to disk.
- Code generation formatting uses a consistent spacing style and utilizes `StringBuilder` extensively in `Clase.java`.
- Variable names given by the user are automatically converted to `camelCase`.
